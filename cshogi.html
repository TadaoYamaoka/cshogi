class cshogi.Board

Bases: object

Board class to represent a Shogi board.

Parameters:

  • sfen (str, optional) – A string representing the board in SFEN format, optional.

  • board (Board, optional) – A string representing the board in SFEN format, optional.

Example:

# Initialize board
board = Board()

# Initialize board with sfen
board = Board(sfen="lnsgkgsnl/1r5b1/ppppppppp/9/9/9/PPPPPPPPP/1B5R1/LNSGKGSNL b - 1")

# Initialize board with board
board2 = Board(board=board)

push(move)

Push a move to the board.

The move is represented as an integer, where each bit has the following meaning:

  • xxxxxxxx xxxxxxxx xxxxxxxx x1111111: Destination square.

  • xxxxxxxx xxxxxxxx xx111111 1xxxxxxx: Source square, or PieceType + SquareNum - 1 when dropping a piece.

  • xxxxxxxx xxxxxxxx x1xxxxxx xxxxxxxx: Promotion flag (1 if promoted).

  • xxxxxxxx xxxx1111 xxxxxxxx xxxxxxxx: Moving piece’s PieceType, not used when dropping a piece.

  • xxxxxxxx 1111xxxx xxxxxxxx xxxxxxxx: Captured piece’s PieceType.

Parameters:

move (int) – The move to be applied to the board, encoded as an integer.

searched_node

Gets the number of nodes searched in the last search.

This is the same count that is compared with the node limit (nodes): it is incremented each time the df-pn search descends into a child position. The root position and the positions examined by the fixed-depth checks (the mate-in-1 check at the root, the 3-ply check at new OR nodes and the 2-ply check at new AND nodes) are not counted. class cshogi.osl.DfPn(depth=1600, nodes=4294967295, draw_ply=2147483646)

Class to perform mate search using the OSL-based df-pn algorithm.

Limitations:

  • Reaching the move limit (depth or draw_ply) on one branch can end the current search iteration before other branches are examined. That iteration is treated as UNKNOWN, and search() may retry with a larger per-iteration node limit, up to nodes. Therefore result can be UNKNOWN even when a checkmate within draw_ply exists, especially when the mate ends at or near draw_ply. A checkmate that exceeds draw_ply is never returned as MATE.

  • A search cut off by draw_ply is UNKNOWN, not NO_MATE.

  • depth limits the depth of the search tree with a margin of two plies, so search() visits no nodes when depth is 1 or 2. At those depths, search_andnode() can still examine the root and return MATE if there is no legal reply to the check.

Use cshogi.DfPn when exact results near draw_ply are needed.

Parameters:

  • depth (int) – Depth of the search.

  • nodes (int) – Number of nodes in the search.

  • draw_ply (int) – The number of plies to consider as a draw.

property searched_node

Gets the number of nodes searched in the last search.

It is incremented each time an attacking or defending position is visited, including the root, and each time a fixed-depth check is performed. Positions where the search stops before being counted, because the depth limit is reached or a loop is detected, are not included, so it can be 0 when the depth limit is small. search() repeats the search while increasing the node limit (iterative deepening), and this is the total over all iterations. Because the node limit (nodes) applies to each iteration and is checked after children are expanded, the total can exceed it.
